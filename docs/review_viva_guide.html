1. Problem Definition & Objectives 100% Ready
What to say to Evaluator:

"Existing commercial platforms (Zoom, Google Meet) impose heavy recurring per-host fees (\$150-\$300/yr), require high-speed broadband (>600 kbps), and drop out completely under rural 2G/EDGE cellular constraints. Swecha Vedika solves this by building an open-source, bandwidth-frugal conferencing platform tailored for rural civic-tech outreach with zero licensing cost."

Key Objectives (O1–O5):
  • O1: Role-Scoped LiveKit SFU routing (saves server egress by separating stage speakers from viewers).
  • O2: Extreme 2G Low-Data fallback mode (≤ 48 kbps downlink; 85% bandwidth reduction).
  • O3: Meta WhatsApp FSM gateway for zero-data RSVP, stage Q&A, and AI digests.
  • O4: Synchronized Replay-as-Live broadcasting clock (t_offset) with real-time live chat and polls.
  • O5: Bilingual speech-to-text live captions (Telugu & English) and standalone offline learning packs (.zip).
2. Literature Review & Research Gap 100% Ready
How Swecha Vedika addresses the Research Gap:
  • Commercial SaaS (Zoom/Meet/Teams): Proprietary closed licensing; bandwidth hungry (600–1800 kbps); no WhatsApp integration; no offline-playable bundles.
  • Open-Source SFUs (Jitsi Meet/BigBlueButton): Heavy server hardware requirements; high egress bandwidth per viewer; no automated Telugu corpus archiving.
  • Swecha Vedika Innovation: Runs on a modest \$10/mo dual-core VPS via Docker Compose; 44.8 kbps 2G mode; WhatsApp front-door bot; time-indexed Telugu Whisper search.
3. System Design & Methodology 100% Ready
Architecture & Tech Stack:
  • Frontend: React 18, Vite, LiveKit Components React, Web Speech API (in-browser speech-to-text).
  • Backend: FastAPI (Python 3.11), SQLAlchemy ORM, Alembic migrations, LiveKit Server SDK, bcrypt auth.
  • Database: PostgreSQL 16 (9 relational tables: users, events, attendance, questions, question_upvotes, polls, poll_votes, chat_messages, alembic_version).
  • Media SFU: LiveKit Server (Go) operating across Ports 7880 (WS signaling), 7881 (TCP), 7882/udp (SRTP media).
4. Implementation & Technical Execution 100% Functional
5 Major Live Working Modules:
  • Live Video Stage: Multi-speaker stage with mic, camera, screen share, and low-latency audio/video.
  • 2G Low-Data Mode: 1-click toggle that disables heavy video and switches to Opus DTX audio at 44.8 kbps.
  • Interactive Sidebar: Stage hand-raising, in-room live chat with Telugu reactions, Q&A upvotes, and real-time polls.
  • WhatsApp Bot: FSM webhook parsing EVENTS, RSVP <id>, ASK <id>: <question>, and SUMMARY <id>.
  • Bilingual Speech-to-Text & Offline Bundler: Real-time Telugu/English live captions and 1-click offline ZIP pack export.

Empirical Results:
